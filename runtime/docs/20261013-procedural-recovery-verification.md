# Verification: Authorized Procedural Recovery

Verified: 2026-10-13
Runtime: 0.5.3

## User Prompt, Verbatim

```text
you do have the authorization for such procedural and budgetary stops. Stop only when it's scientific. Persist that note in the framework.
```

## Implemented Behavior

- Optional goal policy authorizes bounded procedural recovery; legacy goals do
  not gain replacement or budget authority.
- Recovery binds an exact invalid checkpoint, procedural classification,
  released evidence, deterministic correction, fresh campaign/proposal IDs,
  unchanged scientific scope and complete route cost.
- Aggregate accounting exposes the original cap and cumulative recovery
  extension separately. The extension must equal the exact minimum shortfall.
- One replacement per checkpoint is the configurable default used by Accorde.
- Recovery reopens mandatory candidate selection and binds the selected candidate,
  proposal identity, campaign identity and complete budget.
- Failed stores stay closed and charged; invalid evidence remains inadmissible.
- Scientific outcomes cannot use procedural recovery. Explicit user STOP and an
  active campaign still block it.

## Scope

The runtime enforces authorization and accounting; it does not infer that a
failure is procedural. The project must publish evidence for that classification
and freeze a deterministic correction. Scientific nonsupport, inconclusive
evidence and exhausted scientific hypotheses remain legitimate stopping reasons.
